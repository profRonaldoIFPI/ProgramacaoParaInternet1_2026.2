# Referências Bibliográficas

Este repositório reúne materiais e livros de referência sobre desenvolvimento Web (HTML, CSS e padrões Web), organizados no formato de referências bibliográficas da Associação Brasileira de Normas Técnicas (ABNT NBR 6023).

---

## Referências (Formato ABNT NBR 6023)
