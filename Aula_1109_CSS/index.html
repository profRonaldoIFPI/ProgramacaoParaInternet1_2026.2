Por que o CSS foi criado?

Em 1996, Håkon Wium Lie e Bert Bos propuseram o CSS com o objetivo de separar o conteúdo (HTML) da apresentação (estilo visual).

Antes do CSS, os desenvolvedores usavam tags como <font> e atributos como bgcolor diretamente nas tags HTML, tornando a manutenção extremamente difícil e a acessibilidade prejudicada.
