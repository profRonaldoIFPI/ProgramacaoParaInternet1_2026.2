# Programação para Internet I

Repositório de materiais, exemplos e atividades da disciplina **Programação para Internet I** do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (IFPI — Campus Floriano).

A disciplina explora o desenvolvimento da camada de apresentação de aplicações web, unindo os fundamentos da Internet e da Web à construção de interfaces dinâmicas, responsivas e integradas a um servidor básico.

## Conteúdo programático

O conteúdo previsto no plano de ensino está organizado nos seguintes tópicos:

1. **Fundamentos da Web** — história da Web, arquitetura cliente-servidor e protocolo HTTP, incluindo métodos e códigos de status.
2. **HTML5** — estrutura semântica, formulários, recursos multimídia e boas práticas de acessibilidade.
3. **CSS3** — seletores, box model, layouts com Flexbox e CSS Grid, responsividade com media queries e animações.
4. **JavaScript no cliente** — sintaxe básica, manipulação do DOM, eventos, JSON e consumo de APIs com Fetch API.
5. **Introdução ao desenvolvimento no servidor** — configuração do ambiente e criação de um servidor web básico, com rotas e métodos HTTP, utilizando Node.js ou Flask como apoio ao projeto.

As aulas têm caráter teórico-prático e orientado a projetos, com foco na criação de interfaces e na implementação de um produto mínimo viável (MVP).

## Organização do repositório

Para cada aula, será criado um diretório seguindo o padrão:

```
Aula_<data>/
```

Cada diretório poderá conter os códigos desenvolvidos em aula, exercícios, materiais de apoio e demais arquivos relacionados à data correspondente.
