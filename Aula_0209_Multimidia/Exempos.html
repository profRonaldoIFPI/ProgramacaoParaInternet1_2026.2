Aula 4: Multimídia em HTML

Imagens, Áudio, Vídeo e a Web Nativa

1. Imagens: Semântica e Acessibilidade

  • A tag <img> e formatos clássicos: JPEG, PNG, GIF.
  • Atributo alt: O texto alternativo é a voz da imagem.
  • Fundamental para leitores de tela e motores de busca (SEO).

2. Agrupamento Visual: <figure> e <figcaption>

  • Associa semanticamente uma imagem à sua legenda.
  • Preserva o fluxo estrutural (DOM) e enriquece a acessibilidade.

3. Áudio Nativo com HTML5

  • controls: Exibe a interface nativa do reprodutor.
  • preload: Comportamento de buffer (none, metadata, auto).
  • autoplay: Inicia a reprodução automaticamente (quando permitido pelo navegador).
  • loop: Repetição contínua da faixa de áudio.

4. Vídeo Nativo com HTML5

  • Reprodução sem plugins externos via <video>.
  • Atributos dimensionais: width e height.
  • poster: A capa do vídeo antes do carregamento.

5. Múltiplas Fontes: A Cascata de Fallback

  • O elemento <source> resolve o dilema dos codecs (MP4/H.264, WebM/VP8, Ogg/Theora).
  • O navegador lê de cima para baixo e executa o primeiro formato compatível.
  • Se nenhum for compatível, exibe o conteúdo de fallback textual com link.

6. Acessibilidade em Mídia: O Elemento <track>

  • Adição de legendas (subtitles), audiodescrição e transcrições (captions).
  • Utiliza arquivos no formato WebVTT (.vtt).
  • Torna o conteúdo acessível para usuários com necessidades auditivas.

7. Incorporação Externa: O Elemento <iframe>

  • Cria um contexto de navegador aninhado.
  • Ideal para vídeos do YouTube, Google Maps ou ferramentas externas.
  • Delega processamento e armazenamento para servidores de terceiros.

8. Elementos Legados: <embed> e <object>

  • Tags antigas para conteúdo não nativo e plugins genéricos (Flash, Silverlight).
  • Hoje, funcionam como a última linha de defesa na cascata de fallback e para documentos como PDF.

9. Introdução ao <canvas>

  • Uma área de desenho em branco renderizada dinamicamente.
  • Totalmente dependente da API JavaScript.
  • Usado para gráficos, visualizações de dados e jogos no navegador.
Seu navegador não suporta o elemento canvas.

10. Interatividade: A API de Mídia (JavaScript)

  • Controle total sobre o DOM para criar reprodutores personalizados.
  • Métodos principais: play(), pause(), load().
  • Propriedades principais: volume, currentTime, muted.

11. Matriz de Síntese: Qual tag utilizar?

Categoria Tags Hospedagem Interatividade Nativa Uso Ideal
Mídia Nativa <img>, <audio>, <video> Servidor Próprio Alta Controle total e semântica web.
Mídia Hospedada <iframe> Servidor de Terceiros Isolada YouTube, Maps, economia de banda.
Mídia Programática <canvas> N/A Via JavaScript Gráficos dinâmicos, renderização JS.
Legado / Fallback <object>, <embed> Servidor Próprio Via Plugin PDFs, Flash, suporte legado extremo.
