# Atividade de CSS — VOYA Travel

## Objetivo

Edite os estilos das páginas de login e de painel para que a aparência fique o
mais próxima possível das imagens de referência:

- `referencia_login.png` — tela de login;
- `referencia_dasboard.png` — painel.

## Como fazer

1. Baixe ou copie o diretório **Atividade CSS** completo, mantendo sua estrutura
   e todos os arquivos exatamente como foram disponibilizados.
2. Abra `login.html` ou `dashboard.html` no navegador. Se preferir, use a
   extensão Live Server da sua IDE para visualizar as alterações.
3. Edite **somente** o arquivo `style.css` para construir os estilos das duas
   páginas e aproximá-las das referências.
4. Salve o CSS e atualize o navegador para conferir o resultado. Compare cada
   página com sua imagem correspondente e ajuste os estilos até obter a maior
   semelhança possível.

## Regras

- Não altere `login.html` nem `dashboard.html`.
- Não altere, remova ou renomeie imagens, arquivos ou diretórios.
- Não mova arquivos: os caminhos e a estrutura original precisam ser mantidos.
- Faça toda a atividade em `style.css`.

Ao concluir, confira as duas páginas e entregue o diretório com a mesma
estrutura original, contendo suas alterações em `style.css`.
