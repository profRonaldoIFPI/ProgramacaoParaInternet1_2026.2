CSS Layouts e Responsividade

Transição da rigidez das medidas fixas (pixels) para a fluidez das proporções e media queries.

“O design responsivo não é criar múltiplas versões de um site, mas construir um único sistema que ajusta seu design às características do navegador e do contexto.” — Ethan Marcotte (Criador do Conceito de Responsive Web Design)

1. Layout Fluido

Porcentagens (%), Box-Sizing e Flexbox em vez de larguras fixas (960px).

2. Imagens Flexíveis

Uso de max-width: 100% para que mídias respeitem seus contêineres.

3. Media Queries

O motor declarativo condicional (@media) adaptando estilos ao contexto.

Exemplo 2: Media Queries e Paradigma Mobile-First

Construção com Progressive Enhancement (Evolução Progressiva). Começamos com CSS simples e vertical para mobile, e usamos @media (min-width: ...) para expandir em telas maiores.

Anatomia da Regra @media

@media only screen and (min-width: 768px)
@media Declaração condicional
only screen Media Type (tela)
and Operador Lógico
(min-width: 768px) Breakpoint (gatilho)

O Painel Progressivo (Slide 12 na Prática)

Este painel abaixo adapta dinamicamente com base nas regras:
1. Mobile Base: Coluna vertical (flex-direction: column)
2. Tablet (≥ 768px): Linha horizontal (flex-direction: row)
3. Desktop (≥ 1200px): Largura máxima restrita (max-width: 1140px) centralizada

1

Mobile Base (< 768px)

Largura 100%, empilhamento em coluna. Carrega apenas regras leves e essenciais.

width: 100%; flex-direction: column;
2

Tablet (≥ 768px)

Ativado via @media (min-width: 768px). O contêiner agora distribui seus cartões lado a lado.

@media (min-width: 768px) { flex-direction: row; }
3

Desktop (≥ 1200px)

Ativado via @media (min-width: 1200px). Evita linhas longas demais limitando a largura.

@media (min-width: 1200px) { max-width: 1140px; margin: 0 auto; }
