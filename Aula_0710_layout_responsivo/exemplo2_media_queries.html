Código Progressivo com @media

Implementação literal do Slide 12 (Mobile-First: O Código Progressivo). Redimensione a janela para observar as quebras de layout.

Código CSS do Slide 12:

/* 1. Base (Mobile por padrão) */
.painel {
    width: 100%;
    display: flex;
    flex-direction: column;
}

/* 2. Tablets & Viewports Médias */
@media (min-width: 768px) {
    .painel {
        flex-direction: row;
    }
}

/* 3. Desktops & Viewports Grandes */
@media (min-width: 1200px) {
    .painel {
        max-width: 1140px;
        margin: 0 auto;
    }
}
